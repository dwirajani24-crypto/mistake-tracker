# A-Level Mistakes Tracker

A complete standalone PWA for tracking A-Level topic-paper mistakes, exam papers and PIPS mistakes.

## Upload to GitHub

1. Download and unzip this package.
2. Create a GitHub repository.
3. Upload **everything inside the `alevel-mistakes-tracker` folder**, keeping the `icons` folder intact.
4. In GitHub, go to **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Select `main` and `/(root)`.
7. Save and wait for GitHub Pages to publish.

## Install on iPad/iPhone

1. Open the GitHub Pages link in Safari.
2. Tap Share.
3. Choose **Add to Home Screen**.
4. Tap Add.

## Data

Your tracker data is stored locally in the browser. Use **Export** regularly to save a JSON backup and **Import** to restore one.

## Files

- `index.html` — the complete app
- `manifest.json` — PWA manifest
- `sw.js` — offline service worker
- `icons/` — all required app icons
